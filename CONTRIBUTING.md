# Contributing

This playbook gets better when people who actually run small businesses push back on it. Welcome contributions:

## What's welcome

- **Corrections** — typos, broken links, unclear steps.
- **Source updates** — changed AI Act, vendor, privacy, sector, insurer, or data-handling guidance.
- **Case studies** — you applied the ground rules or the stage model in a real business and learned something. Open an issue first so we can place it.
- **Sector notes** — where a rule needs adjusting for a specific industry (agencies, professional services, healthcare-adjacent, trades).
- **Translations** — faithful, credited.

## What isn't

- Anything that weakens the safe-use line (what never goes into AI, no AI decisions about people). Those are load-bearing.
- Vendor or affiliate placements. Tools are named on merit.
- Client, customer, employee, HR, payroll, financial, health, safeguarding, confidential, regulated, proprietary, credential, or personal information in public issues or PRs.

## Standards

Plain, specific, UK English. No hype, no "unlock", no "game-changer". Use public or synthetic examples unless the case is already public. Claims about tool behaviour, data handling, compliance, insurance, or sector duties should use primary or high-authority sources where possible. Open an issue before large changes; PRs reviewed as promptly as a one-person team reasonably can.
